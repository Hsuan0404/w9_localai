    1單元知識速查✔

    ▾

    康軒版五年級上冊第10單元「柱體、錐體與球」，是進入立體幾何的關鍵單元。你將學習柱體、錐體與球的特徵，並計算體積與表面積。

    圖形體積公式表面積公式（參考）康軒教學重點
    圓柱體V = π × r² × h2πr² + 2πrh底面積 × 高
    圓錐體V = ⅓ × π × r² × hπr² + πr × √(r²+h²)體積是相同底面與高的圓柱的三分之一
    球V = 4/3 × π × r³4πr²以半徑 r 計算；無頂點、無棱、無面
    例題（π 取 3.14）： 半徑 4 公分、高 10 公分的圓柱體積 = 3.14 × 4 × 4 × 10 = 502.4 立方公分。

    4第3步：跑通 Gemma 4 26B✔

    ▾
    模型名稱說明： Gemma 家族常見 Ollama 標籤為 gemma3:4b、gemma2:27b 等。若找不到 gemma4:26b，改用可用版本（如 gemma3:4b），步驟完全相同。27B 級大模型約需 16–20 GB 記憶體。

    下載與運行

    ollama pull gemma4:26b
ollama run gemma4:26b

    對話範例

    進入 ollama run 模型名 後，貼入以下提示詞：

    請用國小五年級學生聽得懂的話，解釋「圓柱體體積公式 V = π × r² × h」，並舉一個例題。

    Gemma 4 26B 回答示意：

    圓柱體的體積公式是：V = 底面積 × 高 = π × r² × h

    舉例：半徑 3 公分、高 5 公分的圓柱，
    V = 3.14 × 3 × 3 × 5 = 141.3 立方公分。

    （實際回答會隨模型版本而不同，以上為示範格式。）

    離開對話：輸入 /bye 或按 Ctrl + D。

    5第4步：跑通 Qwen 3✔

    ▾
    Qwen 3 常見標籤：qwen3:4b、qwen3:8b、qwen3:14b、qwen3:32b。記憶體較小建議先用 qwen3:4b 或 qwen3:8b。

    下載與運行

    ollama pull qwen3:8b
ollama run qwen3:8b

    對話範例

    貼入以下提示詞：

    請解釋圓錐體與球的體積公式差異，並說明為什麼圓錐體積是圓柱的三分之一。

    Qwen 3 回答示意：

    圓錐體積： V = ⅓ × π × r² × h

    球體積： V = 4/3 × π × r³，球表面積 = 4πr²

    為什麼圓錐是三分之一？想像用同樣底面和高的圓錐去盛水，倒三次剛好裝滿一個圓柱。

    9第8步：進階 HTTP API 呼叫✔

    ▾

    Ollama 預設在 http://localhost:11434 提供 API，可用程式呼叫本機模型。

    呼叫範例

    # curl
curl http://localhost:11434/api/generate -d '{
  "model": "gemma3:4b",
  "prompt": "請用一句話解釋圓柱體體積公式",
  "stream": false
}'

# Python
import requests
r = requests.post("http://localhost:11434/api/generate", json={
  "model": "qwen3:8b",
  "prompt": "圓錐體積公式是什麼？",
  "stream": False
})
print(r.json()["response"])
    連線失敗代表本機尚未啟動 Ollama，請先執行 ollama serve 或 ollama run 模型名。
